JSON formatter

Pega un JSON y te lo devuelve bonito: sangrado, coloreado y validado. Si no es válido, te dice dónde está el error y qué falta.

Se procesa en tu navegador: el JSON no se envía a ningún sitio.

Errores que se entienden

Línea, columna y una pista concreta: la coma que sobra antes de }, las comillas simples, los comentarios, un True en mayúscula…

Números exactos

Cada número sale tal como entró. JSON.parse convertiría el ID 9007199254740993 en 9007199254740992.

Claves repetidas

Avisa si un objeto repite una clave, algo que JSON permite pero que casi todos los programas resuelven quedándose en silencio con el último valor.

Atajos

Se formatea mientras escribes. Ctrl + Enter fuerza el formateo, y puedes arrastrar un archivo .json a la entrada.
